# olena.studio

Hi, I'm Olena 👋

This repository holds my one-page portfolio at **[olena.studio](https://olena.studio)**. It's where my three lives meet: tech lead, researcher, and someone who can't stop stitching things.

## A small confession

This site was **vibe coded**. I described what I wanted, argued about fonts, cut a caption for being "too cheesy", and an AI assistant (Claude) wrote most of the HTML, CSS and JavaScript.

So please don't judge my engineering by this code. I've reviewed a lot of pull requests in my life, and this one would get comments.

What *is* mine, completely:

- **the ideas**: the cross-stitch theme, the structure, what goes where and why
- **the facts**: every project, number, paper and role on the page is real and mine
- **the words**: drafted together, then rewritten until they sounded like me
- **the art**: every hoop, vase and plate in the studio section, made by hand, slowly

## What's inside

```
index.html            the whole page: HTML, CSS and JS in one file
img/                  photos of my work and paper figures (WebP, lazy-loaded)
og.png                the preview image for shared links
favicon.svg           four little crosses, also in favicon-32.png and apple-touch-icon.png
CNAME                 tells GitHub Pages to answer at olena.studio
```

No framework, no build step, no cookies, no trackers. Just one page you can open in a browser.

## Things I'm a bit proud of

- **You can stitch on it.** Move your cursor (or drag a finger) over the hero and leave crosses behind. Click the star to start over.
- **Folk patterns between sections.** Each one has a small caption on what the motif traditionally means.
- **Accessibility was a requirement from the start.** The page aims for WCAG 2.2 AA:
  - keyboard access throughout
  - a skip link
  - display settings for text size, colours and motion
  - reduced-motion support
  - a light and an aubergine-and-gold dark theme
  
  The honest list of what's tested, and what isn't yet, lives in the page footer.
